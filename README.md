# SQL Advanced Analysis — Questions 22–26

## Project Overview

This project contains 5 practical SQL problems using a **100-row e-commerce orders dataset**.

The focus is on advanced SQL techniques for business and data analysis.

## Questions Covered

* **22.** Find the highest-selling product in each category
* **23.** Calculate running total sales
* **24.** Find customers with multiple order dates
* **25.** Calculate category sales percentage
* **26.** Find the top 2 customers in each category

## SQL Concepts Practiced

* Common Table Expressions (CTEs)
* `RANK()`
* `ROW_NUMBER()`
* `PARTITION BY`
* Window Functions
* Running Totals
* `COUNT(DISTINCT)`
* `GROUP BY`
* `HAVING`
* Percentage Calculations
* Aggregate Functions

## Tools

* MySQL
* MySQL Workbench
* SQL
